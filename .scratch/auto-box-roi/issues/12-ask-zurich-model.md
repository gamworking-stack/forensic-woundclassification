Type: task (HITL)
Status: open
Blocked by: none

## Question

Zimmermann et al. 2023 (Zurich, 1,753 real clinical-forensic photos, wound segmentation) share code and models "on reasonable request". This is the only model trained on real forensic photos. The researcher (or supervisor) emails the corresponding author to ask for the weights and the licence terms for thesis use. Resolved when the reply, or no reply by a set date, is recorded. It informs "4P: which public wound model, or drop the arm" but does not block it.

Rule from "4P: which public wound model, or drop the arm": no waiting. If the model arrives before T19 is frozen, it becomes a 4P candidate under the same selection and gate; if later, it is future work.
